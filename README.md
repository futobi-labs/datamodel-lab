# Data Model Lab

An exploratory notebook on data modeling, published with GitHub Pages at
https://labs.tannerspaulding.com/datamodel-lab/ (and `/datamodel-lab/` on the custom domain once it is set).

Two halves:

- **Field Guide** (`guide/`): what's commonplace in modeling today. Medallion architecture, dimensional modeling, SCDs, conformed dimensions, semantic models, analytic engine layering, naming, metadata-driven pipelines, open questions.
- **Explorations** (`explore/`): interactive D3 views of model *structure*: lineage flow (Sankey), column lineage tracer, star schema explorer, medallion stack (zoomable icicle), bus matrix, engine layer cake.

Sister site: [dataviz-lab](https://github.com/futobi-labs/dataviz-lab).

## How it's built

Plain static HTML, CSS and JavaScript. No build step.

- `assets/js/site.js` holds the site map (`SITE`). Header nav, breadcrumbs, section cards, prev/next and related links are generated from it. Add a page there and it appears everywhere.
- `assets/css/site.css` is the one stylesheet, with light and dark themes and the layer color vocabulary.
- `assets/js/model.js` loads `data/sample-model.json` and indexes it (column ids, upstream/downstream traversal, table-level edges).
- D3 is pinned: `d3@7.9.0` from cdnjs and `d3-sankey@0.12.3` from jsDelivr.
- `.github/workflows/pages.yml` builds the site and publishes it to the `gh-pages` branch on every push to `main`; Pages serves that branch.

## The sample model

`data/sample-model.json` is generated by `tools/build_sample_model.py` (`python3 tools/build_sample_model.py`). It is a small, invented order-to-cash and inventory model: 8 sources, bronze copies and shortcuts, 7 silver entities, a gold star schema (5 dimensions, 3 facts), a Direct Lake semantic model with 13 measures, and 2 reports.

To look at your own model, replace the JSON. The shape is documented on the site's Sample model page (`model/index.html`). Only `layers`, `tables` and `columnLineage` are required.

## Adding a page

1. Copy `guide/_template.html` (or any exploration page) and set `data-section` and `data-page` on `<html>`.
2. Add an entry to the right section in `SITE` in `assets/js/site.js`.
3. Push to `main`.
