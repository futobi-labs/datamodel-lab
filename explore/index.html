Seeing the shape of a model

Charts usually show the data. These show the structure that holds it: tables, columns, keys, measures and the engines between them, from source system to report visual.

Every exploration reads the same file, sample-model.json, which describes a small generic order-to-cash and inventory model in six layers. The layer colors are the same everywhere on the site:

source bronze silver gold semantic report

Start with the lineage flow for the big picture, then use the column tracer to follow one number end to end. For the same journey as a living body, open Data anatomy; to watch a query being answered, open the Semantic engine.
