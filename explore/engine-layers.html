Engine layer cake

An analytics platform is a stack of engines, each doing one kind of work. Pick a report visual and send its query down the stack to see which layer does what, and exactly which model objects it touches on the way.

The sample model is Direct Lake on OneLake.

Query trace

    Two directions, two clocks

    Data moves up the stack on a schedule: pipelines and notebooks write Delta files, the warehouse loads gold, and the semantic model is reframed to the new version. Questions move down the stack in milliseconds: a visual becomes DAX, DAX becomes storage engine scans, and scans read only the columns they need. Most performance problems are one clock doing the other's job, such as a measure recomputing in DAX what a load could have stored once.
